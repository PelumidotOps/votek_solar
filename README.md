# VOTEK — Clean Solar Power Platform

A modern, high-performance clean energy platform empowering homeowners and businesses to eliminate soaring utility bills, transition to clean solar power, and unlock measurable savings.

---

## About VOTEK

VOTEK provides end-to-end clean energy solutions engineered for maximum efficiency, long-term durability, and rapid return on investment. From initial satellite roof assessments to precision installation and 25-year performance warranties, VOTEK makes adopting solar simple, transparent, and investment-free.

---

## Key Features & Capabilities

### ⚡ Intelligent Solar Savings Calculator
A dynamic, multi-step estimation tool that calculates your property's solar potential in under 60 seconds:
- **Property Profiling:** Calibrated for detached homes, semi-detached, terraced properties, bungalows, and flats.
- **Accurate Financial Modeling:** Computes recommended system capacity (kWp), estimated panel count, monthly utility bill offset percentages, and expected net savings.
- **Instant Feasibility:** Delivers clear, honest numbers without high-pressure sales tactics.

### ☀️ Advanced Solar Module Catalog
A comprehensive lineup of tier-1 photovoltaic technologies designed for varied architectural and energy demands:
- **Monocrystalline Panels (400.53 kWp System):** Premium single-crystal black silicon cells delivering 21–23% efficiency, ideal for high output in low-light and residential rooftops.
- **Polycrystalline Panels (350.43 kWp System):** Cost-effective, proven blue silicon wafers offering 17–19% efficiency for larger surface areas.
- **Thin-Film Modules (250.10 kWp System):** Ultra-lightweight and flexible photovoltaic layers engineered for structures with strict roof-load limits.
- **Transparent Solar Glass (600.53 kWp System):** Building-integrated photovoltaics (BIPV) blending natural daylight with active power generation.
- **Solar Roof Tiles (700.33 kWp System):** Sleek, integrated solar slates designed to preserve classic roof aesthetics with 30-year weather protection.
- **Perovskite Tandem Cells (790.49 kWp System):** Next-generation dual-junction solar technology achieving up to 28% efficiency for peak power harvesting.

### 📅 Consultation & Meeting Scheduler
- Direct online booking for 30-minute consultations with certified solar technicians.
- Interactive date and time slot selector with immediate email calendar confirmation.
- Intake forms to capture property specifications, tariff rates, and specific project requirements.

### 🤝 The VOTEK Solar Journey
1. **Roof & Tariff Assessment:** Thorough analysis of energy consumption patterns and roof orientation with zero upfront commitment.
2. **Transparent Savings Report:** Comprehensive ROI forecasts detailing lifetime bill reductions.
3. **Certified Installation:** Quick, safe rooftop integration completed by certified solar engineers in 1–2 days.
4. **Immediate Savings:** Real-time generation tracking and monthly utility bill reductions from day one.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/PelumidotOps/votek_solar.git

# Navigate to project directory
cd votek_solar

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Building for Production

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
